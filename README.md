# 单词抄写 WriteDownSomeWords

Windows 桌面单词学习工具：把词表逐词放大展示，方便把单词、翻译、短语、用法抄进笔记，
也可以切换到背词模式自测。Tkinter 实现，单机运行，无需数据库、无需联网（AI 功能除外）。

> 程序目录里放一个 `.xlsx` / `.json` 词表即可运行；词表属于个人数据，不在本仓库中，
> 可从「在线词库市场」直接下载 qwerty-learner 的词库使用。

## 功能

- 逐词展示：单词、英/美音标、词性提示、翻译、短语、例句、近义词；Tab 展开同根词与词源
- 字号随词条长短自动适配，`Ctrl+滚轮` / `+` `−` 手动缩放
- **背词模式（H）**：隐藏释义、回车看答案；抄写与背词两条进度分开记忆，切模式自动跳回
- **生词标记**：`1` 已掌握 / `2` 生词，侧边栏「只看生词」，一键导出生词本为新的 .json 词表
- **在线词库市场（Ctrl+M）**：浏览并下载 [qwerty-learner](https://github.com/RealKai42/qwerty-learner) 的词库，多镜像加速
- **AI 辅助**：用法搭配生成、义项精简、同根词精简——支持多个 OpenAI 兼容平台并行，结果本地缓存
- 朗读（pyttsx3，换词自动朗读可选）、深浅色主题跟随系统、窗口位置与字号记忆
- 中文输入法开启时单键快捷键也能直达（主窗口自动屏蔽 IME，搜索框临时恢复）

## 使用方法

Windows：双击 `run.bat`，或

```
python words.py [词表.xlsx | 词表.json]
```

依赖 Python 3.10+；可选执行 `pip install -r requirements.txt` 安装拖放切换词表（tkinterdnd2）
与朗读（pyttsx3）支持，不装也不影响其余功能。

## 快捷键

| 键 | 功能 |
| --- | --- |
| 空格 / 回车 / ←→ | 上一个 / 下一个 |
| H | 背词模式开关（回车看答案） |
| 1 / 2 | 标记已掌握 / 生词 |
| R | 随机跳词 |
| Ctrl+F | 搜索单词或中文 |
| Ctrl+M | 在线词库市场 |
| S | 朗读单词 |
| Tab | 展开 / 收起同根词与词源 |
| U / Ctrl+U / Ctrl+Shift+U | 重新生成用法 / AI 精简翻译 / AI 精简同根词 |
| Ctrl+E | 显示内容开关 |
| + / − / Ctrl+滚轮 | 字号缩放 |
| F11 / Esc | 全屏 / 退出 |

## 数据与配置

| 内容 | 位置 | 是否随仓库分发 |
| --- | --- | --- |
| 代码 | 本仓库 | ✓ |
| 词表 / 学习进度 / 生词标记 / AI 缓存 | 程序目录（`.words_state.json` 等） | ✗ 本地生成 |
| AI 平台配置（含 Key） | `%APPDATA%\WriteDownSomeWords\config.json` | ✗ 本地生成 |

在「设置」里可添加任意 OpenAI 兼容平台（Base URL + Key + 模型），按任务勾选用途，多平台可并行。
